# 🧭 Expedición al Valle de las Sombras - 2026 CARHUAZ

Proyecto web desarrollado para el curso de Diseño de Páginas Web.

## 📖 Descripción

Esta página web presenta una historia interactiva ambientada en una expedición ficticia hacia el misterioso Valle de las Sombras.  
El proyecto utiliza diferentes elementos HTML para organizar contenido multimedia, listas, imágenes, enlaces y estilos básicos con CSS.

La historia sigue la travesía del Capitán Elara Voss y su equipo de exploradores durante una expedición ocurrida en 1923.

---

## 🛠️ Tecnologías Utilizadas

- HTML5
- CSS3

---

## 📂 Contenido del Proyecto

- Encabezados y párrafos
- Listas ordenadas y desordenadas
- Glosario con etiquetas `<dl>`
- Imágenes y multimedia
- Enlaces externos
- Código QR
- Estilos básicos con CSS

---

## 🎨 Características del Diseño

- Fondo oscuro estilo exploración/misterio
- Imágenes con bordes redondeados
- Diseño narrativo tipo diario de expedición
- Organización semántica del contenido
